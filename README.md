Este projeto implementa um teste de uso de padrões de projeto.

Simulando um sistema simples de pagamento implementamos uma combinação de padrão Strategy com um padrão Facade.

Não usamos BigDecimal, usamos double pois trata-se apenas de um exemplo de implementação de classes e interfaces.
